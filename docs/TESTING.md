# 验收与测试

## 自动测试

单元测试覆盖二维码凭据、私网地址边界、协议长度与截断数据、二进制视频帧边界、自动画质的观察窗口与冷却策略，以及 LAN 子网匹配、蜂窝 / VPN 地址过滤和不同连接错误的提示。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

FarviewIntegrationTest 在 Android 8.0 模拟器中使用真实 Camera2、H.264 编码器、本地 TLS 套接字、视频解码器及 MediaMuxer，检查首页 / 关于、扫码与拍摄端预览方向与比例、证书拒绝、画面传输、旋转 / 全屏、录像写入 / 解码和断线不续录。扫码与拍摄端预览测试检查画面边缘方向和等比显示，防止重复旋转 90°。模拟器只有一个公开后置镜头，测试通过重启真实相机流触发格式代次变化来验证录像分段；跨物理镜头和 1080p 切换仍需真机补测。测试中的同机发送 / 接收不能证明双机热点、真实性能或厂商后台行为。

LanTransportTest 直接通过 LocalNetwork 选择的 Wi-Fi / 以太网路径建立套接字，验证证书固定的 TLS 和双向读写；同时检查连接失败时关闭原套接字，以及关闭待连接套接字能中止无响应的 TLS 握手。连接页测试验证明确的拒绝连接提示、诊断入口与凭据脱敏。扫码回归测试通过 TextureView 的实际画面更新回调等待帧，避免旧 HAL 的零值或负值时间戳使测试误报。

2026-11-06 已验证：Debug / 未签名 Release APK 构建、24 项单元测试、Android Lint（无错误，保留版本更新等警告）及 8 项 Android 8.0 设备测试通过。集成流程包含扫码预览正向显示、实际录像保存与解码、流重建分段、系统休眠键关闭模拟器显示约 2.5 秒时采集时间继续前进、断线后不续录，以及错误证书拒绝。该短时熄屏测试不能代替目标设备 5–30 分钟验收。vivo X200s / iQOO Neo7 SE 的连接修复结果仍待双机复测，正式 GitHub Release 下载 / 安装及签名覆盖升级尚需发布资产后测试。版本保持 0.1.0 / versionCode 1。

本轮曾在构建与设备回归并行时，于同进程双角色测试切换相机预览期间遇到一次 API 26 系统 `CameraDeviceImpl` / `LegacyCameraCallback` 空指针崩溃；完整设备套件单独复跑后 8 项全部通过。该旧 Camera2 legacy 路径的稳定性仍需观察，不能将一次复跑通过视为问题已修复；本次未改动相机采集实现。

## 双机验收步骤

1. 两台安装包含最新修复的同一个 APK；覆盖已有正式签名安装时使用原 keystore 重新签名。任选一台先开热点，另一台连接，再进入拍摄端配对页并扫码。分别保持移动数据开启、关闭移动数据，确认本地连接、观看、控制、录像都能工作。
2. 切换两台角色和热点提供方，分别重复验证。连接困难时先复制两端连接诊断，再关闭 VPN / 双通道网络加速并重试，检查热点是否隔离设备。刷新二维码后，旧二维码必须失效。
3. 检查公开镜头列表和倍率范围；不能操作的补光 / 分辨率应禁用。切换镜头、滑动变焦、开关补光，核对实际执行与 UI 确认状态。
4. 开始录像，切换镜头和 720p / 1080p。停止后在系统相册逐段播放，确认内容、方向、时长正常且没有声音。
5. 录像时进入全屏，确认 REC 和退出入口可见。手动旋转不改变已保存录像方向。
6. 录像中断开 Wi-Fi，确认旧画面遮罩、录像结束并保存；恢复网络后自动重连，但录像保持停止。主动结束后不得重连。
7. 分别用应用黑屏入口、系统电源键熄屏，持续 5–10 分钟，观看端继续操作和录像。再做约 30 分钟连续测试，检查发热、掉帧、耗电与录像播放。没有 30 分钟强制截止。
8. vivo / iQOO 电池设置若限制后台运行，按系统允许「后台高耗电」等选项，再重复熄屏测试。记录系统版本及所需设置；不把未测结果记为通过。
9. 拒绝相机、通知、旧版存储权限，检查可理解的反馈；相机被其他应用占用、存储不足、系统停止相机时不误报成功。
10. 手动检查更新，在无互联网时显示失败且直播不受影响。结束会话后再进行正式同签名旧版 → 新版更新测试。

## 连接失败诊断

出现一直重试时，保持拍摄端配对页与观看端连接页打开，在两端分别点击「复制连接诊断」。也可从会话中的「关于遥映 → 连接诊断」复制。先收集再结束会话或刷新二维码，避免丢失本次失败记录。

记录哪台手机开热点、哪台拍摄、系统 Android / OriginOS 版本、是否开着 VPN / 双通道网络加速，并附两份文本。拍摄端没有收到 TCP 的记录时，重点检查地址与路由；收到 TCP 但加密握手未完成时，对照两端异常原因链；证书或会话令牌失效时刷新二维码后重新扫码。截图中的重试次数本身不足以判断失败阶段。

## 录像恢复

相册写入失败后，可从「关于遥映 → 恢复未保存的录像」重试。异常退出后当前片段可能没有完整 MP4 索引；测试应区分已完成的可恢复片段与无法读取的临时片段。卸载应用会删除私有缓存中的未保存文件。
